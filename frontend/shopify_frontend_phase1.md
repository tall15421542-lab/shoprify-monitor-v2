Requirement and API document is at @shopify_data_phase2.md
Create minimum frontend with at least three layout
- Store list, support adding shopify store by name and url
- Product list of a store, each product should display
    - Image
    - Name
    - Current price
    - Change compared to previous price
- Dashboard support the following query
    - Query the average price change over time
        - Aggregated by tag
        - Aggregated by store
        - Aggregated by store and tag
- price Changelog of history, for
    - specific product
    - specific tag
    - specific store
